# 💬 問い合わせ / 要望受付

このページでは、Lanske の問い合わせ・要望受付の扱いを整理します。

ver0.1.1 時点では、アプリ内に問い合わせ管理機能は作らず、Google Forms のフィードバックフォームで受け付けます。

---

## フィードバックフォーム

らんすけへのご意見・ご質問・不具合報告・改善案は、以下のフォームから送信できます。

- [らんすけ フィードバックフォーム](https://forms.gle/xbXuJsZnfh5QrqjP8)

返信が必要な場合のみ、フォーム内にメールアドレスを入力してください。

共有URLを送る場合は、URLを知っている人が対戦表を開ける点にご注意ください。
公開したくない情報や、不要に詳細な参加者情報は入力しないでください。

---

## 方針

問い合わせ / 要望受付は、まず外部フォームで受け付けます。

想定:

- Google Forms で受付フォームを運用する
- フォーム URL を README / support docs / アプリ内リンクから案内する
- 回答はスプレッドシート等で管理する
- 必要に応じて GitHub Issue や worklog に転記して開発タスク化する

---

## 外部フォームに寄せる理由

ver0.1.1 では、問い合わせ管理機能をアプリ内に作らない方が運用しやすいです。

理由:

- ログインなし MVP と相性がよい
- 実装コストが低い
- フォーム項目を後から変更しやすい
- スプレッドシートで一覧・集計しやすい
- 要望と不具合報告をまず軽量に受けられる

---

## フォーム設定

フィードバックフォームは、入力ハードルを下げるため、以下の方針で運用します。

- メールアドレスは自動収集しない
- ログイン必須にしない
- 回答は1回に制限しない
- 回答後に別の回答を送信できる
- すべての設問は任意入力とする
- 返信が必要な場合のみ、メールアドレスを入力してもらう

---

## フォーム項目

最初のフォームでは、以下の項目を用意します。

| 項目 | 必須 | 備考 |
|---|---:|---|
| サービスの評価 | 任意 | 1〜5 の星評価 |
| コメント・質問・バグの報告・改善の提案 | 任意 | 自由記述 |
| 返信の必要があればメールアドレス | 任意 | 返信が必要な場合のみ |

---

## 注意点

フォームには、公開したくない個人情報や、不要に詳細な参加者情報を入力しないよう案内します。

特に共有URLを送ってもらう場合は、URLを知っている人が対戦表を開ける前提で扱います。

---

## アプリ内リンクの扱い

ver0.1.1 では、右上メニューからフィードバックフォームへアクセスできる導線を用意します。

フォームは外部 Google Forms とし、アプリ側では回答内容を管理しません。

---

## 開発タスク化

フォームで受けた内容は、必要に応じて次のように扱います。

- 明確な不具合: GitHub Issue 化する
- 仕様確認: docs / FAQ へ反映する
- よくある要望: ロードマップ候補に入れる
- 個別事情が強いもの: すぐ実装せず、類似要望が増えるか見る
