# UI navigation and operation placement

Lanske の AppBar、ナビゲーション Drawer、画面内操作を追加・変更するときの基本方針をまとめる。

## 画面内に残す操作

対戦表など当日の運用中に繰り返し使う操作は、メイン画面から直接利用できるようにする。

ダブルス対戦表では、次の操作・情報をこの分類とする。

- 共有 URL
- 最新情報の更新
- 進行中／次対戦の確認と移動
- 試合結果の入力
- 対戦表そのものの確認

重要な状態遷移は、低頻度でも対象と結果が分かる文字ラベルを伴う操作を優先する。ダブルス対戦表の「この対戦表で確定」は、未確定時のメイン画面に残す。

## 操作メニューへ置くもの

初期設定後は使用頻度が下がる編集・設定操作は、ハンバーガーから開く操作メニューへ集約する。

ダブルス対戦表では、次を操作メニューから利用できるようにする。

- 対戦表一覧
- 最新情報の更新
- イベント情報の編集
- コート表示の変更
- 未確定時の再生成
- 操作ヒントの再表示
- サポート

確定後もイベント情報とコート表示は編集可能とし、メイン画面からは外して操作メニューに残す。再生成と確定操作は確定後に表示しない。

## 操作メニューと対戦表一覧

右側 Drawer は、操作メニューと保存済み対戦表一覧を同じ入口から切り替えて表示する。

- 操作メニュー → 対戦表一覧
- 対戦表一覧の戻る操作 → 操作メニュー
- Drawer 外タップなどで閉じる → 次回は操作メニューから開始

操作メニューは「現在の画面・対戦表に対する操作」、対戦表一覧は「保存済み対戦表の確認・切り替え」という役割を分ける。

ダブルスでは、操作メニュー幅を画面幅の 75%（最大 300px）、対戦表一覧幅を画面幅の 85% とする。情報量の異なる2画面を同じ幅へ固定しない。

操作メニューを開くだけでは、親画面の再 build や対戦表・履歴の再読込を発生させない。ローカルの対戦表表示履歴は「対戦表一覧」へ切り替えた時点で読み込む。サーバー側の最新情報が必要な操作は、明示的な「最新の情報に更新」または各操作の実行前確認で取得する。

対戦表一覧の削除対象選択など未確定のローカル操作は、一覧から操作メニューへ戻る場合や Drawer を閉じる場合にも保存する。

## AppBar

主要画面では、右上のハンバーガーボタンから操作メニューを開く。3点の PopupMenu と右 Drawer を併用して同じ役割の入口を複数作らない。

狭い画面では、操作ボタンのタップ領域を優先し、AppBar タイトルは ellipsis で省略できるようにする。

ダブルス対戦表では通常位置に文字付きの「最新の情報に更新」を残す。対戦表をある程度スクロールして通常位置から離れた場合は、AppBar に更新アイコンを表示して長い対戦表からでも更新できるようにする。上部へ戻ったら AppBar 側の更新アイコンは非表示にする。

## ハンバーガーの操作ヒント

ハンバーガーは主要機能への入口だが、アイコンだけでは意味が伝わりにくい場合があるため、ダブルス画面では初回のみ Tooltip を自動表示する。

- 自動表示は初回のみ
- 表示済み状態は端末ローカルに保存する
- 保存キーにはバージョンを含める
- UI を大きく変更して再案内が必要になった場合は、キーを `v2` などへ更新する
- 操作メニュー内からヒントを再表示できるようにする
- ヒントだけに依存せず、ハンバーガー自体もボタンとして認識しやすい見た目とタップ領域を持たせる

## ダブルスとチームの共通化範囲

ダブルスとチームは、次のナビゲーション原則を共有する。

- AppBar 右側のハンバーガーから右 Drawer を開く
- 操作メニューから対戦表一覧へ切り替える
- サポートなどの補助導線を Drawer にまとめる
- 戻る矢印、ホーム導線、ハンバーガーの役割を重複させない

一方で、Drawer ヘッダーや配色などを完全に同一デザインへ固定しない。各サービスの情報量に応じて簡潔にする。ダブルスの Drawer ヘッダーは、テニスアイコンと「ダブルス乱数表」の1行表示とする。

他サービスへの公開導線は、それぞれの公開時期を扱う Issue で追加する。ナビゲーション整理のためだけに未公開サービスへのリンクを先行追加しない。

## 共通フッター

フッターはアプリ共通の表示とし、各画面や Drawer のスクロール末尾で既存ルールに従って表示する。

サービス名が画面内に常時出ない場合でもアプリ名を識別できるよう、表示は次の構成とする。

`Lanske · © 2026 S.R.P. · ver.<release version>`

フッターの表示タイミングやスクロール末尾判定は、文言変更を理由に個別画面で上書きしない。
